НАЙДЕННЫЕ ДЕФЕКТЫ В КЛАССЕ StringUtils
======================================

1. МЕТОД: capitilize
   ПРОБЛЕМА: Опечатка в названии метода (capitilize вместо capitalize)
   СТРОКА: def capitilize(self, string: str) -> str:
   ВЛИЯНИЕ: Несоответствие стандартному названию метода capitalize()
   ПРИОРИТЕТ: Низкий (функционально работает корректно)

2. МЕТОД: to_list
   ПРОБЛЕМА: Не обрабатывает строку с пробелами вокруг разделителя
   ПРИМЕР: to_list("a, b, c") возвращает ["a", " b", " c"] вместо ["a", "b", "c"]
   ВЛИЯНИЕ: В результат попадают лишние пробелы
   ПРИОРИТЕТ: Средний

3. МЕТОД: contains
   ПРОБЛЕМА: Сложная реализация через try/except вместо простого использования 'in'
   СТРОКА: Используется string.index(symbol) с обработкой исключения
   РЕКОМЕНДАЦИЯ: Заменить на `return symbol in string`
   ПРИОРИТЕТ: Низкий (функционально работает корректно)

4. МЕТОД: list_to_string
   ПРОБЛЕМА: Неэффективная конкатенация строк в цикле
   СТРОКА: string += str(lst[i]) + joiner
   РЕКОМЕНДАЦИЯ: Использовать joiner.join(map(str, lst))
   ПРИОРИТЕТ: Низкий (производительность)

5. МЕТОД: is_empty
   ПРОБЛЕМА: Строка из пробелов считается пустой (может быть неочевидно)
   ПОВЕДЕНИЕ: is_empty("   ") возвращает True
   ОЖИДАНИЕ: Строка из пробелов не должна считаться пустой?
   ПРИОРИТЕТ: Средний (зависит от требований)
